# Student Resource Optimization Dashboard

## Project Overview
This project addresses the **Digital Divide** in education by using an AI-Architected logic engine to segment 500 student records based on academic performance and internet accessibility.

## Key Features
* **AI Logic Engine:** Uses nested `=IFS` logic to automatically categorize students into Critical, High, Medium, and Low risk tiers.
* **Data Scaling:** Expanded a 30-row sample to a 500-row validated database using synthetic data generation.
* **Interactive Dashboard:** Includes Pivot Tables and Visual Charts analyzing the correlation between internet access and student success.

## Tools Used
* **Google Gemini:** Logic Architecture & Prompt Engineering
* **Microsoft Excel:** Data Processing & Visualization
* **Miro:** Data Flow Diagramming (DFD)
